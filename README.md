# Дизайн портфолио — v3

Монгол/Англи хоёр хэлтэй, админ самбартай дизайн портфолио вебсайтын **гурав дахь хувилбар** (`v3` салбар). Нийтийн сайтыг шинээр зохиож байна; админ, өгөгдөл, статистик v2-оос хэвээр шилжсэн.

**Технологи:** Next.js 16 · React 19 · Tailwind CSS 4 · Supabase (өгөгдлийн сан, зураг, нэвтрэлт) · Motion

**Өмнөх хувилбарууд** (GitHub дээр):
- `v2` tag / `version-2` салбар — Figma шиг зотон портфолио (cover нүүр, Pages & Layers, бүтээл бүр тусдаа хуудас)
- `v1` tag / `old-version` салбар — анхны сайт (Next.js 14)

**Ажлын дараалал:** шинэ сайтыг `v3` салбар дээр хийнэ. Vercel энэ салбарт туршилтын хувилбар үүсгэдэггүй (`vercel.json`); бэлэн болмогц `main` руу нэгтгэхэд интернэт дэх сайт шинэчлэгдэнэ.

## Боломжууд

**Нийтийн сайт** — шинэ дизайн хийгдэж байна. Одоогоор `app/[locale]/page.tsx` нь нэр, мэргэжил, бүтээлийн тоог харуулдаг эхлэлийн хуудас.

**Админ самбар** (`/admin`)
- Хянах самбар: үзэлт, давтагдаагүй зочид, өдөр тутмын график, хамгийн их үзэлттэй бүтээл, хаанаас ирсэн зочид
- Бүтээл нэмэх, засах, устгах; чирж эрэмбэлэх; нийтлэх/ноорог; ★ онцлох
- Зураг чирж оруулах. Хөтөч дээрээ 2400px хүртэл жижигрүүлж WebP болгодог тул сайт хөнгөн байна
- Ангилал удирдах, ирсэн мессежүүдийн inbox, сайтын тохиргоо (танилцуулга, сошиал, акцент өнгө, профайл зураг)
- Ctrl + S-ээр хадгалах, хадгалаагүй өөрчлөлтийн анхааруулга

## 1. Шууд үзэх (демо горим)

```bash
npm install
npm run dev
```

http://localhost:3000 хаягаар орно. Supabase тохируулаагүй үед сайт **демо горимд** жишээ бүтээлүүдтэй ажиллана. `/admin` хаягаар админ самбарыг үзэж болох ч өөрчлөлт хадгалагдахгүй.

## 2. Supabase тохируулах (үнэгүй)

1. https://supabase.com дээр бүртгүүлж **New project** үүсгэнэ. Бүс (region) нь хамгийн ойрын Singapore эсвэл Tokyo байвал зүгээр.
2. **SQL Editor → New query** цонхонд [`supabase/schema.sql`](supabase/schema.sql) файлын агуулгыг бүтнээр нь хуулж буулгаад **Run** дарна. Хүснэгтүүд, хамгаалалтын дүрмүүд, зургийн сан, статистикийн функцууд бүгд үүснэ.
3. **Project Settings → API Keys** хэсгээс `Project URL` болон `Publishable key`-г хуулна.
4. Төслийн үндсэн хавтсанд `.env.local` файл үүсгэнэ:

   ```bash
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxx
   NEXT_PUBLIC_SITE_URL=http://localhost:3000
   ```

## 3. Админ хэрэглэгч үүсгэх

1. Supabase → **Authentication → Users → Add user → Create new user** дээр и-мэйл, нууц үгээ оруулна. **Auto Confirm User**-ийг сонгоно.
2. **SQL Editor** дээр дараах командыг ажиллуулж тэр хэрэглэгчид админ эрх өгнө:

   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'таны@имэйл.com';
   ```

3. **Чухал:** Бусад хүн бүртгүүлэхээс сэргийлж **Authentication → Sign In / Providers → Allow new users to sign up**-ийг унтраана. Ингээгүй ч гэсэн `admins` хүснэгтэд байхгүй хэрэглэгч юу ч өөрчилж чадахгүй.
4. `npm run dev` ажиллуулаад http://localhost:3000/admin хаягаар нэвтэрнэ.
5. **Тохиргоо** хэсэгт нэр, танилцуулга, сошиал холбоосоо оруулаад, **Бүтээлүүд** хэсэгт анхны бүтээлээ нэмнэ.

## 4. Интернэтэд гаргах (Vercel, үнэгүй)

1. Кодоо GitHub repository руу push хийнэ.
2. https://vercel.com дээр **Add New → Project** дарж тэр repository-г сонгоно.
3. **Environment Variables** хэсэгт `.env.local` дахь Supabase-ийн 2 хувьсагчийг оруулна. `NEXT_PUBLIC_SITE_URL` заавал биш: Vercel домэйныг өөрөө таньдаг, өөрийн домэйн холбосон бол түүнийг бичнэ.
4. **Deploy** дарна. Дараа нь **Settings → Domains** хэсгээс өөрийн домэйноо (жишээ нь `.mn`) холбож болно.

Админ дээр хийсэн өөрчлөлт сайт дээр шууд шинэчлэгдэнэ. Дахин deploy хийх шаардлагагүй.

## Агуулга бичих зөвлөгөө

- **Нэр:** Тохиргоо хэсэгт кирилл (Төмөрсүх) болон латин (Tumursukh) хэлбэрээр оруулна.
- **Тодотгол өнгө:** Тохиргоо → Тодотгол өнгө. Товч, сонголт зэрэг жижиг тодотгол тэр өнгөтэй болно.
- **Ур чадвар ба хэрэгсэл:** ур чадварыг Тохиргоо → Ур чадвар хэсэгт мөр мөрөөр бичнэ; хэрэгслүүдийг бүтээл бүрийн "Хэрэгсэл" талбараас автоматаар цуглуулж, хэрэглэсэн тоогоор эрэмбэлнэ.
- **Хөрөг зураг:** Тохиргоо → Профайл зураг.
- **Догол мөр:** Тайлбар бичихдээ хоосон мөр үлдээж догол мөр тусгаарлана. Эхний догол мөр томоор харагдана.
- **Хоёр хэл:** Англи талбарыг хоосон үлдээвэл Монгол текст нь харагдана, эсрэгээрээ ч мөн адил.
- **Зураг:** Нүүр зургийг 4:3 эсвэл 16:10 харьцаатай оруулбал хамгийн гоё харагдана. Цомгийн зургийг ⤢ товчоор "бүтэн өргөн" болгож болно.
- **Онцлох бүтээл:** ★ тэмдэглэсэн бүтээлүүдийг шинэ сайт онцолж харуулна.

## Төслийн бүтэц

```
app/
  [locale]/          Нийтийн сайт (mn, en) — v3 дээр шинээр хийгдэж байна
  admin/             Админ: login, (panel)/ хянах самбар, projects, categories, messages, settings
  api/track/         Хуудас үзэлт бүртгэх
components/site/     Нийтийн сайт болон админд хамтдаа хэрэглэгддэг: Img, ThemeToggle, LocaleProvider, ViewTracker
components/admin/    Админы компонентууд (editor, gallery, chart…)
lib/
  data.ts            Нийтийн өгөгдөл (кэштэй, демо горимыг дэмжинэ)
  admin-data.ts      Админы өгөгдөл
  actions/           Server actions (админ, холбоо барих форм)
  i18n.ts            Орчуулга (Монгол / Англи)
  demo-data.ts       Демо жишээ контент
supabase/schema.sql  Өгөгдлийн сангийн бүтэц
```
