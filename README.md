# Дизайн портфолио

Бараан премиум загвартай, Монгол/Англи хоёр хэлтэй, админ самбартай дизайн портфолио вебсайт.

**Технологи:** Next.js 16 · React 19 · Tailwind CSS 4 · Supabase (өгөгдлийн сан, зураг, нэвтрэлт) · Motion · Lenis

## Боломжууд

**Нийтийн сайт**
- **Нүүр хуудас — Figma шиг файл:** бүх сайт нэг хязгааргүй зотон дээр, navbar байхгүй. Гурван хуудастай:
  - **Бүтээл** — танилцуулга фрейм, ангилал бүр нэг фрейм дотор нь бүтээлүүд;
  - **Тухай** (`/#about`) — хөрөг, намтар, тоон үзүүлэлт, ур чадвар ба хэрэгсэл, хамтран ажилласан байгууллагууд;
  - **Холбоо барих** (`/#contact`) — и-мэйл, утас, сошиал, мессеж бичих товч.
- **Pages & Layers самбар** (зүүн талд, утсан дээр гулсдаг цэс): хуудсууд, фрейм ба бүтээлүүдийн мод. Давхарга дээр очиход зотон дээр тодорч, фрейм дээр дарахад тэр рүү нисч очно, бүтээл дээр дарахад дэлгэрэнгүй самбар нээгдэнэ, `↗` товчоор бүтэн хуудсаар нээнэ. Хуудас бүр камерын байрлалаа санана.
- **Хуудасны дэвсгэр (Figma-ийн баруун самбар шиг):** хуудас бүр өөрийн дэвсгэр өнгөтэй. Та админаас (Тохиргоо → Зотны дэвсгэр) анхдагч өнгийг тохируулна; зочин өөртөө зориулж сольж болно (түүний хөтөчид хадгалагдана, ↺ товчоор буцаана). Фреймийн нэр, цэгэн тор дэвсгэрээс хамаарч өнгөө автоматаар тохируулна.
- **Баруун дээд хэрэгслийн мөр:** хамтрагчдын аватар, хэл, хөгжим, тема, "Холбогдох" (мессежийн цонх нээнэ — Figma-ийн Share товчны байранд).
- Чирж аялах, Ctrl + гүйлгэж (утсан дээр хоёр хуруугаар) томруулах, мини газрын зураг, товчлуурууд (`0` бүгдийг харах, `1–9` фрейм, `Ctrl + \` самбар нуух, `?` тусламж).
- "Төмөрсүх" нэртэй хамтрагч курсор хуудас бүр дээр зааж тайлбарлана; зочны заагч дээр "Та" гэсэн шошго дагана.
- **Бүтээлийн дэлгэрэнгүй самбар:** зотон, давхарга эсвэл жагсаалтаас бүтээл дээр дарахад хуудас шилжихгүйгээр баруун талаас өргөн самбар гарна (утсан дээр бүтэн дэлгэцээр). Нүүр зураг, үйлчлүүлэгч/он/үүрэг/хэрэгсэл, тайлбар, цомог. `←` `→` товчоор дараагийн бүтээл рүү шилжихэд зотон араас нь дагана, `Esc` эсвэл хөтчийн «Буцах» товч хаана. Холбоосыг хуваалцаж болно (`/#work/nomad-coffee`); Ctrl/⌘ + товшвол бүтэн хуудсыг шинэ табд нээнэ. Нээсэн бүтээл бүр статистикт үзэлтээр тоологдоно.
- **Жагсаалт харагдац:** "Зотон | Жагсаалт" сэлгэгч — бүх бүтээлийг хурдан харах, хулганы доор зураг нь гарна (`/#list`).
- Figma-ийн өнгөтэй бараан (#1E1E1E) ба гэрэл (#F5F5F5) горим: анхдагчаар зочны системийн тохиргоог дагана, тойрог хэлбэрээр сольж болно. Тодотгол нь хар-цагаан. MN / EN хэл сэлгэх
- **Lo-fi радио:** FigJam шиг хөгжмийн тоглуулагч. Хөгжмийг хөтөч өөрөө Web Audio-гоор зохиож тоглуулдаг (файл татахгүй, зохиогчийн эрхийн асуудалгүй, хэзээ ч яг давтагдахгүй). 6 ая, дууны түвшин, дараагийн ая; хуудас солигдоход тасрахгүй. Зочин өөрөө асаана.
- Соронзон товчнууд, асааж унтраадаг товшилтын дуу (тоглуулагчийн цонхонд), film grain эффект
- Бүтээл бүрийн дэлгэрэнгүй хуудас (parallax нүүр зураг, цомог, "Дараагийн төсөл"), холбоо барих форм (спам хамгаалалттай)
- Хуучин `/about`, `/contact`, `/work` хаягууд зотны тохирох хуудас руу автоматаар шилжинэ
- SEO: sitemap, robots, хэл бүрийн meta, Open Graph

**Админ самбар** (`/admin`)
- Хянах самбар: үзэлт, давтагдаагүй зочид, өдөр тутмын график, хамгийн их үзэлттэй бүтээл, хаанаас ирсэн зочид
- Бүтээл нэмэх, засах, устгах; чирж эрэмбэлэх; нийтлэх/ноорог; ★ онцлох (нүүр хуудсанд гарна)
- Зураг чирж оруулах. Хөтөч дээрээ 2400px хүртэл жижигрүүлж WebP болгодог тул сайт хөнгөн байна
- Ангилал удирдах, ирсэн мессежүүдийн inbox, сайтын тохиргоо (танилцуулга, сошиал, акцент өнгө, профайл зураг)
- Ctrl + S-ээр хадгалах, хадгалаагүй өөрчлөлтийн анхааруулга

## 1. Шууд үзэх (демо горим)

```bash
npm install
npm run dev
```

http://localhost:3000 хаягаар орно. Supabase тохируулаагүй үед сайт **демо горимд** жишээ бүтээлүүдтэй ажиллана. `/admin` хаягаар админ самбарыг үзэж болох ч өөрчлөлт хадгалагдахгүй.

## 2. Supabase тохируулах (үнэгүй)

1. https://supabase.com дээр бүртгүүлж **New project** үүсгэнэ. Бүс (region) нь хамгийн ойрын Singapore эсвэл Tokyo байвал зүгээр.
2. **SQL Editor → New query** цонхонд [`supabase/schema.sql`](supabase/schema.sql) файлын агуулгыг бүтнээр нь хуулж буулгаад **Run** дарна. Хүснэгтүүд, хамгаалалтын дүрмүүд, зургийн сан, статистикийн функцууд бүгд үүснэ.
3. **Project Settings → API Keys** хэсгээс `Project URL` болон `Publishable key`-г хуулна.
4. Төслийн үндсэн хавтсанд `.env.local` файл үүсгэнэ:

   ```bash
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxx
   NEXT_PUBLIC_SITE_URL=http://localhost:3000
   ```

## 3. Админ хэрэглэгч үүсгэх

1. Supabase → **Authentication → Users → Add user → Create new user** дээр и-мэйл, нууц үгээ оруулна. **Auto Confirm User**-ийг сонгоно.
2. **SQL Editor** дээр дараах командыг ажиллуулж тэр хэрэглэгчид админ эрх өгнө:

   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'таны@имэйл.com';
   ```

3. **Чухал:** Бусад хүн бүртгүүлэхээс сэргийлж **Authentication → Sign In / Providers → Allow new users to sign up**-ийг унтраана. Ингээгүй ч гэсэн `admins` хүснэгтэд байхгүй хэрэглэгч юу ч өөрчилж чадахгүй.
4. `npm run dev` ажиллуулаад http://localhost:3000/admin хаягаар нэвтэрнэ.
5. **Тохиргоо** хэсэгт нэр, танилцуулга, сошиал холбоосоо оруулаад, **Бүтээлүүд** хэсэгт анхны бүтээлээ нэмнэ.

## 4. Интернэтэд гаргах (Vercel, үнэгүй)

1. Кодоо GitHub repository руу push хийнэ.
2. https://vercel.com дээр **Add New → Project** дарж тэр repository-г сонгоно.
3. **Environment Variables** хэсэгт `.env.local` дахь Supabase-ийн 2 хувьсагчийг оруулна. `NEXT_PUBLIC_SITE_URL` заавал биш: Vercel домэйныг өөрөө таньдаг, өөрийн домэйн холбосон бол түүнийг бичнэ.
4. **Deploy** дарна. Дараа нь **Settings → Domains** хэсгээс өөрийн домэйноо (жишээ нь `.mn`) холбож болно.

Админ дээр хийсэн өөрчлөлт сайт дээр шууд шинэчлэгдэнэ. Дахин deploy хийх шаардлагагүй.

## Агуулга бичих зөвлөгөө

- **Нэр:** Тохиргоо хэсэгт кирилл (Төмөрсүх) болон латин (Tumursukh) хэлбэрээр оруулна.
- **Тодотгол өнгө:** Тохиргоо → Тодотгол өнгө. Анхдагч нь өнгөгүй (хар-цагаан); өнгө сонговол товч, сонголт зэрэг жижиг тодотгол тэр өнгөтэй болно. Дэвсгэр Figma шиг саарал хэвээр.
- **Ур чадвар ба хэрэгсэл:** ур чадварыг Тохиргоо → Ур чадвар хэсэгт мөр мөрөөр бичнэ; хэрэгслүүдийг бүтээл бүрийн "Хэрэгсэл" талбараас автоматаар цуглуулж, хэрэглэсэн тоогоор эрэмбэлнэ.
- **Хөрөг зураг:** Тохиргоо → Профайл зураг. "Тухай" хуудсанд гарна.
- **Онцлох үг:** Нүүр хуудасны гол өгүүлбэрт `*үг*` гэж одоор хүрээлбэл serif налуу, акцент өнгөтэй харагдана. Жишээ: `Хүмүүсийн сэтгэлд *үлдэх* брэнд бүтээдэг.`
- **Догол мөр:** Тайлбар бичихдээ хоосон мөр үлдээж догол мөр тусгаарлана. Эхний догол мөр томоор харагдана.
- **Хоёр хэл:** Англи талбарыг хоосон үлдээвэл Монгол текст нь харагдана, эсрэгээрээ ч мөн адил.
- **Зураг:** Нүүр зургийг 4:3 эсвэл 16:10 харьцаатай оруулбал хамгийн гоё харагдана. Цомгийн зургийг ⤢ товчоор "бүтэн өргөн" болгож болно.
- **Онцлох бүтээл:** ★ тэмдэглэсэн бүтээлүүд нүүр хуудсанд гарна (хамгийн ихдээ 6). Нэгийг ч тэмдэглээгүй бол эхний 6 бүтээл гарна.

## Төслийн бүтэц

```
app/
  [locale]/          Нийтийн сайт (mn, en): (home) зотон, (pages) бүтээлийн дэлгэрэнгүй work/[slug]
  admin/             Админ: login, (panel)/ хянах самбар, projects, categories, messages, settings
  api/track/         Хуудас үзэлт бүртгэх
components/site/     Сайтын компонентууд (canvas/ — зотон, давхаргын самбар, камер; music/ — lo-fi радио; cursor…)
components/admin/    Админы компонентууд (editor, gallery, chart…)
lib/
  data.ts            Нийтийн өгөгдөл (кэштэй, демо горимыг дэмжинэ)
  admin-data.ts      Админы өгөгдөл
  actions/           Server actions (админ, холбоо барих форм)
  i18n.ts            Орчуулга (Монгол / Англи)
  demo-data.ts       Демо жишээ контент
supabase/schema.sql  Өгөгдлийн сангийн бүтэц
```
